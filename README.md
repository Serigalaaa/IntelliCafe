# IntelliCafe: An Interactive and Intelligent Web-based Café System

IntelliCafe is a modern web-based café system developed as a Final Year Project (FYP). The system integrates intelligent web features such as an AI-powered chatbot, interactive games, smart menu browsing, and role-based user access.

---

## Core Features

### Authentication
- Customer login and registration
- Admin login
- Guest mode access
- Secure authentication via API routes and MongoDB

### Main Functionalities
- Smart digital menu with category filtering
- AI chatbot with bilingual support (English & Malay)
- Emoji-based customer feedback system
- Interactive mini-games (Memory Game & Categorization Game)
- Admin dashboard for management and monitoring

---

## Technology Stack

- **Frontend**: Next.js 15, React, TypeScript
- **Styling**: Tailwind CSS, shadcn/ui
- **Backend**: Next.js API Routes
- **Database**: MongoDB (Local or Atlas)
- **AI**: Vercel AI SDK (OpenAI GPT-4o-mini)
- **Icons**: Lucide React
